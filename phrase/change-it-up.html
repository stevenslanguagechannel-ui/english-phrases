change it up

Phrasal verbLevel B1CasualEveryday life

To do something differently so it does not get boring.

I walk to work every day, so sometimes I change it up and take the bus.

Tip: Say 'change it up' (or 'change things up') when you vary a routine; 'it' refers to the routine, so don't add another object after it.

Hear it in conversation

AmiraYou look tired, Ken. Still doing the same gym routine every morning?
KenYeah, and honestly I'm bored of it. I keep skipping days.
AmiraMaybe you should change it up. Try a class or go for a run instead.
KenGood idea. There's a swimming pool near my flat that I've never used.
AmiraPerfect. Let me know how it goes on Monday!

Show an example answer

I usually study at the same desk every evening, but it gets boring after a while. So now and then I change it up and work at a café or the library. It helps me stay focused and feel more motivated.

Answer key: change it up

  1. 1. D. Do something in a different way so it feels less boring
  2. 2. change it up
  3. 3. A. Why not change it up? Try something shorter this time.
  4. 4. Example: I usually study at the same desk every evening, but it gets boring after a while. So now and then I change it up and work at a café or the library. It helps me stay focused and feel more motivated.
