feel run down

ExpressionLevel B2NeutralFeelings & reactions

To feel tired and a little unwell.

I feel run down after working so much.

Tip: Use it with 'feel' (or 'be'/'get'): 'I've been feeling run down lately.' It describes general tiredness and low energy, not a specific illness, so don't use it for a broken leg or a clear diagnosis.

Hear it in conversation

AmiraYou look pale, Kofi. Are you getting enough sleep?
KofiNot really. I've been feeling run down since the product launch.
AmiraMaybe you should take a day off before you catch something.
KofiI might. I've got a slight sore throat already.
AmiraThen go home and rest. I'll cover your meeting this afternoon.
KofiThanks, Amira. That would really help.

2. Fill the gap

3. Choose the best reply

4. Your turn: speak

Tell me about a time when you felt run down. What caused it, and what did you do to feel better?

Answer out loud in 2–3 sentences and use the phrase. Then compare with the example answer.

Show an example answer

Last winter I felt run down for almost a month because I was studying late and not eating properly. I kept getting small colds and had no energy at all. In the end I slept earlier, cooked at home more often and started going for short walks, and slowly I felt like myself again.

Answer key: feel run down

  1. 1. D. Feeling tired and not quite healthy
  2. 2. run down
  3. 3. B. Honestly, I've been feeling a bit run down this week.
  4. 4. Example: Last winter I felt run down for almost a month because I was studying late and not eating properly. I kept getting small colds and had no energy at all. In the end I slept earlier, cooked at home more often and started going for short walks, and slowly I felt like myself again.
